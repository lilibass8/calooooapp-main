# Source (`src`)

هذا المجلد يحتوي على منطق تطبيق CalorieSnap القابل لإعادة الاستخدام، بينما بقي
مجلد `app` في الجذر لأن Expo Router يكتشف صفحات التطبيق منه مباشرة.

## التنظيم

- `components`: مكونات الواجهة المشتركة.
- `context`: حالة التطبيق ومزوّد البيانات.
- `services`: حساب السعرات، تجهيز الوجبات، والاتصال بالبيانات.
- `storage`: التخزين المحلي.
- `theme`: الألوان والمسافات والتصميم.
- `types`: أنواع TypeScript المشتركة.
- `data`: بيانات تجريبية مرجعية للتطوير والعرض.
